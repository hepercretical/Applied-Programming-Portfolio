# JLite

This program translates data from a .json file into a .sqlite database to be used for more robust backend data storage.

## Instructions for Build and Use

Steps to build and/or run the software:

1. The .jar does require java to be installed on your computer. (for example OPENJDK Platform Binary)
2. The software can be run by simply running the .jar file, which starts the program and launches the GUI.

Instructions for using the software:

1. Select a .json file via the GUI that you would like to move it's data into a database.
2. Select a location for your .sqlite database file to be made.
3. Verify that the data is consistant and correct.
